How this is calculated

  • SolarWinds Observability SaaS uses an à-la-carte, modular subscription: each capability area is licensed independently by active entities or consumption measured in the previous calendar day.
  • Network & Infrastructure (NICO) is priced by active network devices and infrastructure hosts. Weighting: network device / hypervisor / host / storage array 1:1; wireless AP & container 10:1; standalone VM & cloud service 3:1. When one device is monitored via multiple channels it counts once; ICMP-only status nodes are free.
  • APM is per active service (independent of the number of running instances). Database is per active instance. RUM is per 100,000 pageviews/month. Synthetics is licensed in bundles of 10 checks — a bundle holds either 10 uptime checks or 2 scripted transactions. Uptime checks are derived as endpoints × locations × protocols (e.g. 20 endpoints × 2 locations × 1 protocol = 40 uptime checks); when private probes are used, each private probe adds to the location count before multiplying. Logs is a monthly plan measured per GB ingested.
  • No customer backend to size — storage, processing, and the web application are hosted by SolarWinds. Customer-side sizing covers only collectors and agents: the Network Collector (≤7,000 standard devices each; min 4 CPU/16 GB, rec 8 CPU/32 GB, 40 GB + SQL), the lightweight per-host SolarWinds Observability Agent (OTLP 443, no central server), the SWO K8s Collector for clusters, and optional dedicated flow collectors (≤40,000 flows/sec each). APM libraries and RUM run in-app; synthetics use SolarWinds public probes (or optional agent-based private probes).

How this is calculated

  • OSH Essentials and Advanced use simple node-based tier licensing. ICMP-only availability nodes are free; a node becomes billable once additional monitoring (apps, interfaces, NCM profiles, or other services) is enabled. Cloud/hypervisor-discovered VMs are free until additional monitoring is assigned, then count as one full node.
  • Essentials includes NPM, SAM, LA, IPAM, UDT, VNQM and cloud monitoring. Advanced adds flow monitoring (NTA), NCM, VMAN, SCM, ML anomaly-based alerting, and the security vulnerability dashboard. WPM, SRM, Incident Response and the attached SWO SaaS (NICO) license are Premier-only and are not included here.
  • Value-based (fractional) licensing and license overages/bursting are Premier-only features and are excluded from this Essentials/Advanced sizing.
  • Scale edition: Standard includes additional web servers and allows HA as an add-on but does not include APEs. If sizing needs one or more APEs, or capacity exceeds 1,500 nodes, an Enterprise license is required. Enterprise also bundles HA, EOC, lab licenses and Advanced Support.
  • Polling engine count is the maximum across workload dimensions: elements ÷ protocol capacity (SNMPv2 100k / SNMPv3 72k / WMI 20k, at 16 cores), SAM components ÷ 40,000, flows ÷ 50,000 FPS (Advanced only), agents ÷ 1,000, and WMI's 2,000-node cap. Each instance supports up to 100 APEs and 1,000,000 elements.
  • Server hardware tiers (CPU/RAM) follow SolarWinds Platform 2026.2 system requirements; element-heavy pollers need 16 cores to reach the protocol caps, and more cores raise the cap further. Recommended adds a headroom tier plus redundancy: an HA database pair, an extra APE, and an additional web server.

How this is calculated

  • Premier uses node-based tier licensing and scales like Essentials/Advanced; ICMP-only nodes are free until additional monitoring is enabled. Cloud VMs ~3:1, containers ~10:1, thin APs 10:1 (confirm against the live license report).
  • WPM & SRM are included and unlimited in Premier today (Silicon 2026.2) and do not consume nodes; from Tungsten 2026.4, SRM is planned at ~5 nodes/array. IR Pro is bundled by tier; SaaS (NICO) aligns 1:1.
  • OSH poller count is the maximum across workload dimensions: elements ÷ protocol capacity (SNMPv2 100k / SNMPv3 72k / WMI 20k, at 16 cores), SAM components ÷ 40,000, flows ÷ 50,000 FPS, agents ÷ 1,000, and WMI's 2,000-node cap. Each instance supports up to 100 APEs and 1,000,000 elements.
  • Server hardware tiers (CPU/RAM) follow SolarWinds Platform 2026.2 system requirements; element-heavy pollers need 16 cores to reach the protocol caps, and more cores raise the cap further.
  • SaaS network devices are sized by the Network Collector (≤7,000 standard devices each; a standard device is SNMPv2 with ~15 interfaces). SaaS servers are monitored by the per-host Observability Agent (no central server; sends via OTLP 443) or agentlessly through a collector. Flow monitoring is ≤40,000 flows/sec per collector.
  • Recommended adds a headroom tier plus redundancy: HA database pair, an extra APE, an additional web server, and a standby / dedicated flow collector.
