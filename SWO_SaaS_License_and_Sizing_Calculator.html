How this is calculated

  • SolarWinds Observability SaaS uses an à-la-carte, modular subscription: each capability area is licensed independently by active entities or consumption measured in the previous calendar day.
  • Network & Infrastructure (NICO) is priced by active network devices and infrastructure hosts. Weighting: network device / hypervisor / host / storage array 1:1; wireless AP & container 10:1; standalone VM & cloud service 3:1. When one device is monitored via multiple channels it counts once; ICMP-only status nodes are free.
  • APM is per active service (independent of the number of running instances). Database is per active instance. RUM is per 100,000 pageviews/month. Synthetics is licensed in bundles of 10 checks — a bundle holds either 10 uptime checks or 2 scripted transactions. Uptime checks are derived as endpoints × locations × protocols (e.g. 20 endpoints × 2 locations × 1 protocol = 40 uptime checks); when private probes are used, each private probe adds to the location count before multiplying. Logs is a monthly plan measured per GB ingested.
  • No customer backend to size — storage, processing, and the web application are hosted by SolarWinds. Customer-side sizing covers only collectors and agents: the Network Collector (≤7,000 standard devices each; min 4 CPU/16 GB, rec 8 CPU/32 GB, 40 GB + SQL), the lightweight per-host SolarWinds Observability Agent (OTLP 443, no central server), the SWO K8s Collector for clusters, and optional dedicated flow collectors (≤40,000 flows/sec each). APM libraries and RUM run in-app; synthetics use SolarWinds public probes (or optional agent-based private probes).
